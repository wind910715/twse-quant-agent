# 量＋均線策略回測 v1（VPVR 支撐版）

凍結規格：`量價均線策略_凍結規格_v1.md`（2026-10-30 使用者確認凍結，測完不改）。
本目錄為實驗分支專用：不動 main、不動 monitor／screener、不寫 latest_backtest.json、
純回測（無外部通知、無憑證、無交易指令）。

## 規格摘要
- 宇宙 11 檔：2330、6669、8299（.TWO）、8046、2376、3711、2308、6488（.TWO）、2409、2327、0050。
- 價格與量：yfinance 日線，與主系統 backtest.py 同呼叫（不指定 auto_adjust）。
- 窗口：交易 2025-11-01～2026-10-30，暖機自 2025-09-01 起；日線做多，訊號日 T 收盤判、次日 T+1 開盤進。
- 底：收盤_T ＞ MA20_T，且最低_T 觸及 VPVR 支撐區（最低_T ≤ 支撐區高，且收盤_T ≥ 支撐區低；收盤跌破支撐區低者跳過）。
- VPVR：T 前 60 個交易日（T-60～T-1，不含 T）日線量按價位分箱，箱寬 = 1% × 收盤_T；
  POC 為量最大箱，價值區為以 POC 為中心擴至 70% 量之最小區間；
  HVN 為量 ≥ 1.5 倍均箱量之箱；支撐區為現價之下或等於現價之 HVN 箱（含 VAL 所在箱），
  壓力區為現價之上之 HVN 箱（含 VAH 所在箱，僅記錄、不入 v1 進場條件）。
- 對照：P1（MA20 趨勢＋MA10 拉回），與 VPVR 底分開計，不得合併為同時成立。
- 出場：ATR14（訊號日含 T 向前 14 日真實波幅簡單平均）停損掃描 0.5／1.0／1.5／2.0 倍，
  停利固定 2 倍停損，同日兩觸先判停損，最晚持有 20 個交易日收盤平倉；
  成本現股標準 net% = gross% − 0.585。支撐破位出場不入 v1。
- 濾網一個一個加測：底、底＋CDP（收盤_T ＞ CDP_T，CDP 以前一日高／低／收經典公式算）、
  底＋布林（20 日 2σ，收盤_T ≤ 上軌_T）、底＋MACD（12／26／9，MACD_T ＞ Signal_T），
  各自獨立對照底；三者個別皆通過後才測底＋三者全上，個別未過者不入第二階段。

## 實作選擇（規格未明訂處，事前寫死）
- 每根日線的全日成交量歸入收盤價所在分箱；均箱量 = 窗口總量／有量分箱數。
- 價值區擴張：自 POC 箱出發，逐次向相鄰箱中量較大的一側擴張（量相等時先向下擴張），
  直到累計量 ≥ 70% 窗口總量或無相鄰箱可擴。
- VPVR 窗口須滿 60 根：資料不足者跳過該訊號日，計入 coverage 的 skipped_insufficient_vpvr
  （暖機自 2025-09-01 起，2025 年 11 月上旬訊號多未滿 60 根，屬規格內排除）。
- 布林標準差採樣本標準差（pandas std，ddof=1）；MACD 為 EMA12／EMA26（adjust=False）之差，
  Signal 為 DIF 的 9 日 EMA（adjust=False）。
- 兩半切法：以 2330 在交易窗口內的交易日序列對半切，交易按進場日歸屬；切點寫入結果檔。
- 累計淨報酬 = 已實現交易淨報酬 % 之和（非複利）；MDD 以該累計曲線（按出場日排序）的峰值回落計（百分點）。
- 窗口末未觸停損／停利者採剔除不計（censored），每組報剔除筆數。
- 全贏組合（無虧損筆）RR 記為通過；無贏筆組合 RR = 0。
- 第二階段門檻：三個單濾網臂各至少一組停損倍數通過六項，才計算全上臂；否則門檻關閉。

## 過關六項（全過才算找到）
n ≥ 30、RR ≥ 1.5、勝率 ≥ 45%、期望值 ＞ 0、累計 ＞ 0 且 MDD ≤ 20%、
兩半淨皆 ＞ 0 且後半 RR ≥ 1.0、單一檔貢獻 ≤ 50%。任一項未過即不通過。

## 執行方式
- 完整回測一律走 GitHub Actions：`.github/workflows/vpvr-ma.yml`（手動觸發 only），
  派發：`gh workflow run vpvr-ma.yml --ref exp/vpvr-ma-v1`。
  結果推回本分支（`vpvr_ma_results.json`、`vpvr_ma_report.md`），另加 artifact 備份。
  結果推回時絕不 rebase 到 main，一律直接 push HEAD 到本分支，失敗要大聲失敗。
- 本機只做冒煙檢查（1–2 檔，確認可跑與欄位齊全，不當正式結論）：
  `python exp_vpvr_ma/vpvr_ma_backtest.py --smoke --out /tmp/vpvr_smoke.json`
